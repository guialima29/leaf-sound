Substituir o stub de `src/components/NoteEditor/index.tsx` pela implementação completa:
```tsx
interface NoteEditorProps {
  noteId: string;
  onBack?: () => void;
}
```
Funcionalidades obrigatórias:
1. **Estado e Carga**:
   - Buscar a nota em `storage.getNote(noteId)`.
   - Manter estados `editorData` (OutputData), `noteTitle`, `isSaving`, `isLoading`, `lastSaved`.
   - Exibir estado de carregamento com `<Spinner />` centralizado (`min-h-[400px] flex justify-center items-center`) enquanto os dados da nota carregam.
2. **Auto-save com Debounce & Flush Imediato**:
   - Usar `useDebounce` (ou timer ref) para salvar automaticamente alterações no conteúdo após ~3 segundos.
   - Criar uma função de salvamento `flushSave(dataToSave?)` que salva imediatamente no `storage.saveNote({ id: noteId, content: data, description: ... })`.
   - No teardown do `useEffect` (quando `noteId` muda ou o componente desmonta), garantir que alterações pendentes sejam salvas imediatamente antes de trocar para outra nota (D-13).
3. **Sincronização de Título**:
   - Ao alterar o título via `<TitleWithBar editable onTitleChange={handleTitleChange} />`:
     - Atualizar o estado local `noteTitle`.
     - Chamar `renameNote(noteId, newTitle)` de `useWorkspace()`.
     - Salvar `storage.saveNote({ id: noteId, title: newTitle })`.
4. **Sem EditorHeader**:
   - NÃO renderizar `EditorHeader` (D-04).
   - Renderizar no topo uma barra discreta com:
     - Botão/breadcrumb sutil à esquerda (`onBack`): ex. `<Button variant="ghost" size="sm" onClick={onBack} className="text-xs text-muted-foreground hover:text-foreground">← Ver todas as notas</Button>`.
     - Indicador discreto `<SpinnerBadge isSaving={isSaving} lastSaved={lastSaved} />` à direita.
5. **Corpo do Editor**:
   - Renderizar `<TitleWithBar title={noteTitle} editable onTitleChange={...} />`.
   - Renderizar `<TextEditor key={noteId} initialData={editorData} onChange={handleChange} />` garantindo remount limpo ao trocar `noteId`.
